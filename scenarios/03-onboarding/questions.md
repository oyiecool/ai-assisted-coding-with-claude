# Orientation questions (Chapter 10, 10.1; scenario 3)

Run these in **plan mode** so nothing changes while you learn. Ask for
`file:line` citations so you can check every answer.

1. What does this system do, for whom, and how is it deployed?
2. List the main modules and how they depend on each other.
3. Trace one real request end to end, citing file:line for each step.
4. Where is configuration read, and which settings matter most?
5. How do I run it locally, and how do I run the tests?
6. Which parts look oldest or riskiest, and why?
7. What does this codebase do that a newcomer would not expect? Look at
   decorators, middleware, signals, dependency injection and anything
   registered by naming convention.

Then write the answers into `ONBOARDING.md` using `ONBOARDING-template.md`,
marking every claim that could not be confirmed from the code as UNVERIFIED.
